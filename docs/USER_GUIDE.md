# Stuffy — User Guide

Stuffy is a little hamster that lives on your Windows screen and does things when you **talk** to it.
Say **"Stuffy, open YouTube"** and it opens YouTube. Say **"Stuffy, volume 50"** and the volume changes.

Everything happens **on your own computer**. Stuffy has no account, no cloud and no AI chatbot,
and it never sends your voice to the internet.

## 2. Install Stuffy (3 steps)

### Step 1 — Download

Go to the **[Releases page](https://github.com/tellapriyatham05/stuffy-voice-assistant/releases/latest)**
and click **`Stuffy-Setup-2.0.0.exe`** to download it (about 700 MB, because the voice brains are inside).

### Step 2 — Run the installer

Double-click the downloaded file. There's nothing to choose: it installs and starts by itself.

> **If you see a blue "Windows protected your PC" box:**
> click **More info** → **Run anyway**.
> This appears because Stuffy is a free personal project without a paid publisher certificate.

> **If your antivirus (Avast, AVG, etc.) blocks or deletes Stuffy:**
> this is a false alarm. Stuffy starts itself with Windows and presses keys for you,
> which some antivirus programs find suspicious. Open your antivirus → **Exceptions** →
> add the folder `C:\Users\<your name>\AppData\Local\Programs\stuffy\`, then install again.

### Step 3 — Allow the microphone

The first time, Windows may ask whether Stuffy can use the microphone: click **Yes / Allow**.

If Stuffy says *"Microphone not available"*:
open **Settings → Privacy & security → Microphone** and switch on
**Microphone access** and **Let desktop apps access your microphone**.

✅ **That's it.** Stuffy now starts by itself every time you turn on the computer.

## 3. First start

1. The hamster appears in the **bottom-right corner** of your screen, in a little home with a wheel.
2. For a few seconds it says **"Stuffy is waking up…"** while it loads its voice brains.
3. Then it says **"Stuffy is ready"**. Try:

> 🗣️ **"Stuffy, what time is it?"**

Stuffy answers out loud and shows the time in a bubble.

**Move it:** drag the hamster anywhere you like. It remembers the spot.

## 4. How to talk to Stuffy

### The basic rule

Say **"Stuffy"** first, then what you want, **in one sentence**:

> 🗣️ "Stuffy, open Chrome"
> 🗣️ "Stuffy, search best phones under 20000"
> 🗣️ "Stuffy, play Believer"

### Three handy tricks

**1. Pause after "Stuffy" if you like.** Say *"Stuffy"*, wait for the hamster to perk up
(you'll hear a little sound), then say the command within 8 seconds.

**2. Keep going without "Stuffy".** After a command, Stuffy keeps listening for **8 seconds**:

> 🗣️ "Stuffy, open YouTube" → "search lofi music" → "full screen"

**3. Chain commands with "and" / "then":**

> 🗣️ "Stuffy, open Gmail **and** new tab **then** open WhatsApp"

### Speak naturally

Polite words are fine: *"Stuffy, can you please open Spotify for me"* works.

### When Stuffy is not sure

- It shows **"Sorry, I didn't get that"** and what it heard → just say it again, a bit clearer.
- For **restart / shut down / sign out**, Stuffy asks **"Are you sure?"** → say **"yes"**.
  Anything else (or silence) cancels it.
- If several buttons have the same name, Stuffy puts **numbers** on them → say the number.

| 🙈 **Hide Stuffy** but keep it listening | "Stuffy, hide" · "Stuffy, come back" |
| 🕒 **Time and date** | "Stuffy, what's the date" |

### A few features explained

**Typing.** When you say *"type …"*, Stuffy listens to that sentence a second time with a more
careful (slower) brain to get every word right, so typing takes a second longer than other commands.

**Dictation.** Say *"Stuffy, start dictation"*. Now everything you say is typed into whatever box
is active. Say punctuation as words: *"comma"*, *"full stop"*, *"question mark"*, *"new line"*,
*"new paragraph"*. Say *"stop dictation"* to finish (it also stops after 20 seconds of silence).

**Click by name.** Stuffy reads the buttons and links on screen. *"Click Sign in"* clicks the
button called "Sign in". If it can't find a name, use numbers instead.

**Click by number.** *"Show numbers"* puts a small number on every clickable thing. Then say just
the number (*"7"*), or *"double click 7"*, *"right click 7"*, or *"type into 3 hello"*.
Numbers disappear after 30 seconds or when you say *"hide numbers"*.

**Timers and reminders.** When time is up, the hamster rings a bell and says it out loud.
They're kept even if you restart the PC. A reminder missed while the PC was off (in the last
12 hours) is told to you when Stuffy starts again.

**Focus Dot.** If you also use the **[Focus Dot](https://github.com/tellapriyatham05/focus-dot)**
app, Stuffy can add, start, pause and finish its tasks and save notes, all by voice.

**Wallpaper.** Put your favourite pictures in **Pictures › Wallpapers**. Each *"change wallpaper"*
shows the next one.

**Screenshots** are saved in **Pictures › Screenshots**.

| Shortcut / action | What it does |
|---|---|
| **Ctrl + Alt + S** | Same as saying "Stuffy": listen for a command now. Also turns listening back on after "stop listening". |
| Ctrl + Shift + Alt + S, or **F9** | Used instead of Ctrl + Alt + S if another app already took it (the menu shows which one you have) |

| **Right-click the hamster** | Opens Stuffy's menu |
| **Drag the hamster** | Move it anywhere |
| **Tray icon** (near the clock, maybe under the **^** arrow) | Click for the same menu |

Right-click the hamster (or click the tray icon) to see:

| Menu item | What it does |
|---|---|
| **Listen for a command now** | Same as saying "Stuffy" |
| **Hide Stuffy from screen / Show Stuffy on screen** | Hides the hamster; it **keeps listening** |

| **Language for typing & searches** | English · Auto-detect (English / Hindi / Telugu) · Hindi · Telugu. Commands are always in English; this changes the language of *typed* text and searches. |

| **Stuffy's voice** | **Chatty**: talks every time · **Short**: only answers and questions · **Silent**: squeaks only |

| **Start with Windows** | Start Stuffy automatically when you sign in (on by default) |
| **Move Stuffy back to the corner** | If you lost it off-screen |

## 9. Make your own commands

A **custom command** is one name that does several steps. Two come built in:

- *"Stuffy, **work mode**"* → opens Chrome, Slack and Gmail
- *"Stuffy, **music time**"* → opens YouTube Music and sets volume to 40

### Way 1 — Record one by voice

1. *"Stuffy, **start recording**"*
2. Give your commands normally: *"Stuffy, open Gmail"*, *"Stuffy, volume 30"*, …
3. *"Stuffy, **save as morning routine**"*

Now *"Stuffy, morning routine"* repeats all those steps. (*"cancel recording"* throws it away.)

### Way 2 — Type them in the editor

Right-click the hamster → **My commands & routines…** (or say *"Stuffy, open my commands"*).

![Commands editor](screenshots/commands-editor.png)

1. Click **+ New command**.
2. Type the **name** (what you'll say after "Stuffy").
3. Type the **steps**, one per line, exactly as you'd say them.
4. Each line gets a ✓ (Stuffy understands it) or ✗ (it doesn't; reword that line).
5. Click **Save** (or Ctrl + S). Use **▶ Run** to test it.

You can run them as *"Stuffy, morning routine"*, *"Stuffy, run morning routine"* or
*"Stuffy, start morning routine"*.

## 10. Tips for best results

- **Say "Stuffy" clearly at the start**, then the command without a long gap.
- **Short, plain commands work best**: *"open Spotify"* rather than a long story.
- **Use a headset** or sit near the mic in noisy rooms.
- **Wait for the result** before the next command; Stuffy ignores talk while it's busy.
- Stuffy ignores speech that doesn't start with "Stuffy" (except the 8-second follow-up window),
  so videos and people talking nearby won't trigger it.
- **Names in other languages** (like Telugu or Hindi song names) can be misheard in English mode.
  Try *"search …"* and check the result, or switch **Language** to Auto-detect.
- Stuffy only types into the **active** window, so click the box you want first.

## 11. Problems and fixes

| Problem | Fix |
|---|---|
| **I can't see the hamster** | Say *"Stuffy, come back"*. Still nothing? Right-click the tray icon → **Show Stuffy on screen**, or **Move Stuffy back to the corner**. |
| **Stuffy doesn't react to "Stuffy"** | Is the house curtain closed (paused)? Press **Ctrl + Alt + S**. Check the mic is plugged in and allowed (Step 3 of install). |
| **"Microphone not available"** | Plug in the mic, then Settings → Privacy & security → Microphone → allow desktop apps. Stuffy retries automatically. |
| **It hears the wrong words** | Speak a bit slower, closer to the mic, with less background noise. Use "show numbers" for clicking. |
| **"Sorry, I didn't get that"** | Say it again in the simplest form, or check the [Cheat Sheet](VOICE_COMMANDS.md) for the right words. |
| **Websites open in the wrong browser** | Menu → **Open websites in** → pick Chrome or Default browser. |
| **"Focus Dot isn't running"** | Start the Focus Dot app, then try again. |
| **"No wallpaper pictures found"** | Put some pictures into **Pictures › Wallpapers**. |
| **Stuffy disappeared after a while / after a reboot** | Your antivirus may have removed it. Add the exception (see [Install](#step-2--run-the-installer)) and reinstall. Your settings are kept. |
| **Stuffy doesn't start with Windows** | Menu → make sure **Start with Windows** is ticked. Or just open **Stuffy** from the Start menu. |
| **Something else** | Menu → **Open activity log** shows exactly what Stuffy heard and what went wrong. |

## 12. Uninstall

**Settings → Apps → Installed apps → Stuffy → ⋯ → Uninstall.**

Your settings and custom commands stay in `%APPDATA%\stuffy` in case you reinstall.
Delete that folder too if you want everything gone.

---

## 13. Privacy

- 🎙️ Your voice is turned into text **on your computer**. Nothing is recorded to disk or sent anywhere.
- 🌐 Stuffy only uses the internet when *you* ask it to open a website or search.
- 📝 The activity log (`%APPDATA%\stuffy\stuffy.log`) stays on your PC and only contains text.
- 🔗 The Focus Dot link only talks to `127.0.0.1` (your own PC) with a private key.
